Balena Block Experiments
========================

This repository is dedicated to experimentation and prototyping in 
relation to the docker-derived Balena framework for deployment and 
management of IoT applications, and specifically the use of the 
'Blocks' feature of that framework which allows community members
to publish balena/docker container images on their BalenaHub site
for potential re-use in applications where an image with a generic
function (for example an X-Windows display server) is re-used
alongside a developer's custom image with a domain-specific behaviour
(for example an application to control and provide audio output
from a specific make/model of Midi keyboard).

See documentation published by Balena at 
https://hub.balena.io/blocks 
for details of the Blocks framework.
